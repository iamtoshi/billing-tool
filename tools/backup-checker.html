Bills Backup Checker

For Deo Ratan Billing backup files. It shows which bills are in each file, which ones are missing from the current one, and can put them all back into one bills file.

Works offline. Your files are only read inside this window. Nothing is uploaded, and closing the window clears everything.

All times are India time (IST), on any computer. Backup file names use the clock of the computer that made them.

Drag the files here: bills-data.json and the files from the Backups folder.

You can add more files at any time.
